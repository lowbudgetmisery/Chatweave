YouTube channel emojis (member emojis)

YouTube only sends emoji codes like :_lumiHeart: to the app, never the picture.
Put the picture here, named after the code without the colons:

    :_lumiHeart:   ->   _lumiHeart.png

Works with .png .gif .webp .jpg .jpeg .avif. Names match exactly first, then
ignoring capital letters. New files are picked up while the app runs; refresh the
OBS browser source to see them.

Codes with no picture here show as a small neat label instead of raw text.
